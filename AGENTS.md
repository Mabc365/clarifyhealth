# Project architecture rules

- Preserve Clarify Health's existing routes, tools, translations, authentication, and data behavior during visual redesigns; visual shell changes must not alter product functionality.
- Use semantic design tokens from `src/index.css` for all interface colors so light, dark, and high-contrast modes remain coherent.
- Core public pages share the full-width editorial shell, directory grid, mono labels, and two-tier floating navigation so the experience stays visually consistent.
